# Lumen 1.0.4

This release improves library reliability, Discover searches, and wallpaper performance.

- Imports now roll back copied files when a batch fails, and library save failures are reported.
- New Discover searches keep their results when an older request finishes later. Repeated clicks no longer create duplicate downloads.
- Imported images are cached, and recommendation requests pause briefly while API keys are being edited.
- Display selection follows the built-in screen even when another screen becomes active.
- Short videos can generate a wallpaper preview from their first frame.
- The Swift source is organized into app, model, service, and view files.

Requires macOS 14 or newer. Download `Lumen-1.0.4.dmg`, open it, and drag Lumen to Applications.
