# Lumen 1.0.5

This release makes browsing and switching wallpapers feel smoother.

- Wallpaper previews crossfade when switching, including a brief wait for video to show its first frame.
- Navigation, cards, and buttons have subtle transitions that respect macOS Reduce Motion.
- Library video cards use cached poster images instead of running paused video players.
- Hover over a downloaded wallpaper in Discover to remove it from your library after confirmation.
- CPU and fullscreen status updates cause fewer unnecessary dashboard redraws.
- Imports, Discover searches, and display selection include the reliability fixes prepared for 1.0.4.

Requires macOS 14 or newer. Download `Lumen-1.0.5.dmg`, open it, and drag Lumen to Applications.

This DMG is ad-hoc signed because no Developer ID certificate is configured for this release. macOS may warn that it cannot verify the developer. After confirming the download is from this repository, Control-click Lumen in Applications and choose **Open**, or use **System Settings > Privacy & Security > Open Anyway** after a blocked launch.
