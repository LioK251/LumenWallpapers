# Lumen 1.0.6

This update fixes the preview transition introduced in 1.0.5. Wallpaper changes now visibly crossfade, and library rows respect macOS Reduce Motion.

It also includes the smoother navigation, cached video posters, and Discover hover-to-delete controls from 1.0.5, plus the reliability improvements prepared for 1.0.4.

Requires macOS 14 or newer. Download `Lumen-1.0.6.dmg`, open it, and drag Lumen to Applications.

This DMG is ad-hoc signed because no Developer ID certificate is configured for this release. macOS may warn that it cannot verify the developer. After confirming the download is from this repository, Control-click Lumen in Applications and choose **Open**, or use **System Settings > Privacy & Security > Open Anyway** after a blocked launch.
