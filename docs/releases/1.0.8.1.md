# Lumen 1.0.8.1

Fixes the previous static wallpaper appearing when you choose a different wallpaper and lock your Mac before quitting Lumen. The macOS wallpaper now updates when you select it, when Lumen starts, and when displays change.

Selected videos animate through the native macOS Desktop and Idle wallpaper selection. **Video Wallpaper** is enabled by default and stays enabled when switching through images, so selecting the next video restores native animation. The catalog continues to reuse one entry named **Lumen**. You can turn the option off in Settings to use a still frame; procedural scenes use a still preview on the lock screen.

This hotfix also restores native files if video installation fails, handles Spaces created after the original wallpaper backup, switches safely before deleting an active wallpaper, preserves photo orientation, and fixes display targeting and sleep playback edge cases.

Requires macOS 14 or newer. Download `Lumen-1.0.8.1.dmg`, open it, and drag Lumen to Applications. Both the app and helper support Apple silicon and Intel Macs.

The DMG is ad-hoc signed and is not notarized. If macOS blocks the app, confirm that you downloaded it from this repository, then use **System Settings > Privacy & Security > Open Anyway**.
