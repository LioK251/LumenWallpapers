# Lumen 1.0.8

Fixes the old live wallpaper returning after switching to a static image and quitting Lumen. Background helpers now reject stale sessions, handle rapid reopen/quit handoffs, and stop when their settings are removed or invalid. Saved desktop images use content-specific paths so macOS can distinguish the new wallpaper from its cached preview.

Native wallpaper cleanup preserves unrelated desktop and screen saver changes. If saving your chosen wallpaper fails, Lumen stays open and reports the problem. The native Video Wallpaper catalog continues to use one reusable entry named **Lumen**.

Lumen now checks GitHub for updates on launch and when returning to the app, at most once every six hours during a session. Each newer stable release gets one popup, remembered across launches. **View Release** opens its GitHub page; Settings also includes a GitHub link and the installed version.

Requires macOS 14 or newer. Download `Lumen-1.0.8.dmg`, open it, and drag Lumen to Applications. The app and background helper support both Apple silicon and Intel Macs.

This DMG is ad-hoc signed because no Developer ID certificate is configured for this release. macOS may warn that it cannot verify the developer. After confirming the download is from this repository, use **System Settings > Privacy & Security > Open Anyway** after a blocked launch.
